# v1.1 — 設定功能

## Project Information

Project Name: WinClock

Version: v1.1

Feature Name: 設定（開機啟動、系統匣、字型、視窗顏色、時間格式、鬧鐘預設值）

Status: Approved（2026-11-25）

---

# Product Vision

## Problem Statement

開機啟動、字型、視窗顏色、時間格式、鬧鐘參數目前都寫死在程式裡，使用者無法調整。

## Target Users

在桌面常駐顯示時鐘的使用者。

## Business Value

使用者不改程式就能調整啟動行為與外觀。

---

# Version Objective

新增系統匣與設定視窗，保存並套用設定。

## 使用者提出的需求（2026-11-25）

1. 開機是否自動啟動
2. 自動啟動狀態（縮到最小、預設顯示）
3. 中文字型
4. 時鐘（數字）字型
5. 視窗顏色：可以漸層；明亮與暗色分開設定

## Success Criteria

- [ ] 所有 FR 的驗收項目通過
- [ ] 設定寫入 `settings.json`，重新啟動後還原
- [ ] `settings.json` 不存在或損毀時，程式用預設值啟動，不當機

## Non Goals

- 字級設定（維持現行行為）
- 多色標漸層（只做 2 色）
- 鬧鐘上限設定（維持 5 個）
- 匯入／匯出設定

# Functional Requirements

## FR-001 設定檔

設定存成 exe 旁的 `settings.json`。

Acceptance Criteria:

- [ ] 按「確定」後寫入；重新啟動後還原所有設定
- [ ] 檔案不存在、內容損毀或缺欄位時，用預設值，不當機
- [ ] `release.bat` 發佈時保留 `settings.json`

## FR-002 系統匣

常駐系統匣圖示。選單項目：顯示、設定、結束。

Acceptance Criteria:

- [ ] 點兩下圖示或選「顯示」，主視窗顯示並取得焦點
- [ ] 選「設定」開啟設定視窗；已開啟時切到前景，不開第二個
- [ ] 選「結束」關閉程式，系統匣圖示消失
- [ ] 主視窗的最小化按鈕縮到系統匣，工作列不顯示（Q9）

## FR-003 設定視窗

左側導覽，右側內容。底部按鈕：確定、取消、重設此類別、全部重設。入口：系統匣「設定」、主視窗齒輪按鈕。

Acceptance Criteria:

- [ ] 修改時主視窗即時預覽
- [ ] 「確定」寫入設定並關閉
- [ ] 「取消」或關閉視窗時，主視窗還原成開啟前的設定
- [ ] 「重設此類別」只重設目前類別；「全部重設」重設所有類別；兩者都要按「確定」才寫入（Q10）

## FR-004 一般設定

- 開機自動啟動（開／關）
- 開機啟動狀態：預設顯示／縮到系統匣
- 永遠在最上層（開／關）
- 時間格式：12／24 小時制；顯示秒數（開／關）

Acceptance Criteria:

- [ ] 開機啟動寫入 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，關閉時移除
- [ ] exe 搬移後啟動，登錄的路徑自動更新
- [ ] 「縮到系統匣」只套用在開機啟動；手動開啟一律顯示
- [ ] 最上層、時間格式立即套用

## FR-005 外觀設定

- 主題：明亮／暗色／跟隨 Windows
- 中文字型、數字字型：字型＋粗細；數字一律等寬
- 明亮、暗色各一組：背景（單色或 2 色漸層＋角度 0–360°）、文字顏色、透明度

Acceptance Criteria:

- [ ] 「跟隨 Windows」時，系統切換主題後主視窗跟著切換
- [ ] 主視窗工具列的主題按鈕與本設定同步
- [ ] 字型清單列出系統已安裝字型；設定的字型不存在時退回預設字型
- [ ] 秒數跳動時，數字不左右晃動

## FR-006 鬧鐘設定

- 預設鈴聲（內建 4 個）
- 音量 0–100
- 貪睡分鐘數（目前固定 5）

Acceptance Criteria:

- [ ] 新增鬧鐘時預先選好預設鈴聲
- [ ] 鈴聲用設定的音量播放
- [ ] 貪睡使用設定的分鐘數

# Non Functional Requirements

## Reliability

- 設定檔損毀不影響啟動；`alarms.json` 格式不變

## UI Testability（規則見 `docs/kb/00-ui-rules.md` §1）

- 設定視窗、系統匣選單、齒輪按鈕與所有控制項都設 `AutomationProperties.AutomationId`
- 本版例外與原因：系統匣圖示本身不是 WPF 控制項，無法設 AutomationId

## Window State Persistence（規則見 `docs/kb/00-ui-rules.md` §2）

- 設定視窗記憶位置（走 DWToolkit `WindowPersistence`）
- 本版要保存的視窗客製項目：設定視窗最後選取的類別

---

# Initial Technical Direction

- 開機啟動：`HKCU\...\Run`，參數加 `--autostart`，讓程式分辨開機啟動與手動開啟
- 系統匣：⬜ 待決定（WinForms `NotifyIcon` 或第三方套件）→ ADR
- 字型、顏色：`MainWindow.xaml` 寫死的 `FontFamily` 與 `WindowBackground` 改成動態資源
- 主題：與既有 `btnThemeToggle`（DWToolkit 擴充狀態）整合，不另建第二套主題

---

# ADR Candidates

- 設定檔格式與位置
- 系統匣實作方式
- 開機啟動登記方式
