## 版號

- 維護階段的版號是 1.0.x。第三碼由 Nerdbank.GitVersioning 依 commit 數自動產生，不手動修改 `version.json`。
- 小的功能異動直接放進 1.0.x。
- 項目符合〈Maintenance〉的「次版號建議條件」時，Claude 向使用者建議改排進 v1.1。使用者決定。
