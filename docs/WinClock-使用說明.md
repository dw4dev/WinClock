# WinClock 使用說明

> 本檔隨 WinClock 發行。可以直接閱讀，也可以交給 AI 助理，請它依本檔回答使用問題。
>
> **給 AI 助理**：只依本檔內容回答。本檔沒寫的功能，回答「說明書沒有提到」，不要猜測。

## 1. WinClock 是什麼

WinClock 是 Windows 桌面時鐘。主視窗顯示：

- 日期與星期，例如 `2026/11/26 (四)`
- 農曆日期，節氣當天另外顯示節氣標籤
- 時間（12／24 小時制，可顯示秒數）
- 左下角：版本號
- 右下角：錨定燈號與提示（見第 4 節）

## 2. 安裝與啟動

1. 把 `WinClock.exe` 放到任一資料夾。
2. 執行 `WinClock.exe`。不需要安裝程式。
3. 設定與鬧鐘存在 exe 同一個資料夾的 `*.json` 檔（`settings.json`、`alarms.json` 等）。搬移程式時，把這些檔案一起搬。

## 3. 主視窗操作

### 3.1 工具列（由左到右）

| 按鈕 | 功能 |
|---|---|
| 圖釘 | 切換「永遠在最上層」。開啟時按鈕底色為綠色 |
| 鬧鐘按鈕（帶編號） | 每個生效中的鬧鐘一個按鈕。點擊可修改或移除；滑鼠停留顯示剩餘時間 |
| `+` | 新增鬧鐘。最多 5 個，額滿時隱藏 |
| 太陽／月亮 | 切換明亮／暗色主題 |
| 齒輪 | 開啟設定視窗 |
| `−` | 縮到系統匣 |
| `×` | 結束程式 |

### 3.2 移動與縮放

- 移動：在視窗空白處按住左鍵拖動。
- 縮放：拖動右下角的點狀把手。字體大小跟著視窗寬度等比例變化。
- 程式會記住視窗位置與寬度。

## 4. 錨定模式

錨定模式把時鐘固定在桌面上，適合當作桌面裝飾。

### 4.1 進入與退出

- **進入**：按住 `Ctrl`，在時鐘上雙擊左鍵。
- **退出**：按住 `Ctrl`，在時鐘上雙擊左鍵。
- **備用出口**：在系統匣圖示選單點「顯示」，也會退出錨定。

### 4.2 錨定時的狀態

- 工具列與縮放把手隱藏。
- 視窗不能拖動。
- 滑鼠點擊會穿透時鐘，直接點到下方的視窗或桌面。
- 只有按住 `Ctrl` 時，時鐘才接收滑鼠點擊。
- 切換時，視窗底部位置不動。
- 錨定狀態不會保存。重新啟動程式後，一律是一般模式。

### 4.3 燈號

右下角固定顯示燈號和提示文字（「Ctrl+雙擊 進入錨定」或「Ctrl+雙擊 退出錨定」）。

| 狀態 | 燈號 |
|---|---|
| 一般模式 | 灰 |
| 一般模式，按住 `Ctrl`（可以雙擊進入） | 綠 |
| 錨定模式 | 紅 |
| 錨定模式，按住 `Ctrl`（可以雙擊退出） | 黃 |

剛退出錨定、`Ctrl` 還沒放開時，燈號維持灰色。

## 5. 鬧鐘

### 5.1 新增與修改

1. 點工具列的 `+`。
2. 在「設定鬧鐘」視窗設定日期、時間。
3. 需要時勾選「顯示文字」並輸入提醒內容。
4. 需要時勾選「播放音效」，選擇鈴聲；可按「試聽」。
5. 按「確定」。

- 修改：點該鬧鐘的工具列按鈕，改完按「確定」。
- 移除：點該鬧鐘按鈕，按「清除鬧鐘」。

### 5.2 鬧鐘響起

時間到時，程式移除該鬧鐘，並顯示訊息視窗：

- 貪睡按鈕：在設定的分鐘數後再響一次。
- 「關閉」：結束提醒。

主視窗縮到系統匣時，鬧鐘照常響起。程式結束後再啟動，尚未到時間的鬧鐘會還原。

## 6. 系統匣

- 點「`−`」或按 `Win+M` 時，主視窗縮到系統匣。
- 雙擊系統匣圖示：顯示主視窗。
- 系統匣圖示選單：
  - 「顯示」：顯示主視窗（並退出錨定模式）
  - 「設定」：開啟設定視窗
  - 「結束」：結束程式

## 7. 設定視窗

點齒輪或系統匣「設定」開啟。修改會即時預覽；按「確定」保存，按「取消」還原。「重設此類別」和「全部重設」會回到預設值。

### 7.1 一般

- 開機時自動啟動
- 開機啟動時：顯示視窗，或縮到系統匣
- 永遠在最上層
- 時間格式：12 小時制／24 小時制；顯示秒數

### 7.2 外觀

- 主題：明亮、暗色、跟隨 Windows
- 明亮與暗色主題各自設定：
  - 背景顏色、不透明度
  - 使用漸層（漸層第二色、漸層角度）
  - 文字顏色
  - 農曆與文字顏色一致；取消勾選後可另設農曆顏色
- 字型：數字字型、中文字型（各自可選粗細）、縮放比例

### 7.3 鬧鐘

- 預設鈴聲：新增鬧鐘時預先選好的鈴聲
- 音量
- 貪睡分鐘數

## 8. 常見問題

**Q：點不到時鐘，也拖不動？**
A：時鐘在錨定模式（燈號紅色）。按住 `Ctrl` 並雙擊時鐘退出，或從系統匣選單點「顯示」。

**Q：工具列不見了？**
A：同上，時鐘在錨定模式。

**Q：主視窗不見了？**
A：時鐘縮到系統匣。雙擊系統匣的 WinClock 圖示，或在圖示選單點「顯示」。

**Q：如何把時鐘固定在桌面、又不擋住點擊？**
A：使用錨定模式（第 4 節）。

**Q：重灌或換電腦時要備份什麼？**
A：備份 `WinClock.exe` 所在資料夾裡的 `*.json` 檔。
